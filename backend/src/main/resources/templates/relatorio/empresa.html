Como ler este relatório

Índice de movimento da carreira

Cada alternativa vale pontos. A soma das respostas de cada líder vira uma escala de 0 a 100: 0 quando todas as escolhas são as de menor pontuação e 100 quando todas são as de maior.

Cada dimensão usa o mesmo cálculo, só com as perguntas dela. O índice de cada pergunta é a média dos líderes que a responderam, na mesma escala de 0 a 100.

Os percentuais são arredondados para que cada distribuição some 100%.
